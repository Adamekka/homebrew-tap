# Adamekka Tap

## How do I install these formulae?

`brew install adamekka/tap/<formula>`

Or `brew tap adamekka/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "adamekka/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
