# Adamekka Tap

## How do I install these formulae and casks?

`brew install adamekka/tap/<formula>`

Or `brew tap adamekka/tap` and then `brew install <formula>`.

For a cask, use `brew install --cask adamekka/tap/<cask>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "adamekka/tap"
brew "<formula>"
cask "adamekka/tap/<cask>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
